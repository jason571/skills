# 按年级写讲解稿

`grade` 是变量，取值 `小学一年级` … `小学六年级`。用户指定几就按几写。一年级、二年级、三年级、四年级、五年级、六年级同一套流程，没有「只处理某两个年级」。

下面各年级条目是**默认认知水平**，用来决定怎么想、怎么讲、画面多密、口播多长。不是只允许讲这些知识点。用户要求超前或补旧，以用户为准，但讲解方式仍必须匹配该年级的理解方式。

## 先定年级

1. 用户说了年级 → 用这个年级，不改成「更好讲」的另一个年级。
2. 用户没说 → 按题目通常出现的年级填写，并说明「按小学X年级来讲」。拿不准就问。
3. 题目相对该年级过难 → **降维**：只讲这个年级能抓住的意思，并标明完整做法以后再学。不要把高年级算法原样塞进来。
4. 题目相对该年级过易 → 仍用该年级的口头和画面，不要突然改用高年级讲法。
5. 同一题换年级必须重写 `narration` 和 `visual`，不能只改 `grade`。

## 适配规则（每个年级都要套）

对当前 `grade` 逐项决定：

| 维度 | 问自己 |
| --- | --- |
| 怎么想 | 这个年级看见题目时，脑海里是实物、步骤，还是关系？ |
| 怎么讲 | 先图、先故事、先步骤名，还是可以问「为什么」？ |
| 词 | 哪些词必须换成大白话？新词是否立刻配图？ |
| 步数 | 一次能跟几步？多余的拆段。 |
| 画面 | 用哪些图形及动作让关键过程可见？需要哪些短标签、算式或小结？ |
| 口播 | 句子长度、自然停顿是否适龄？时长以真实 TTS 音频为准。 |

禁止（所有年级）：

- 成人讲座腔、一次丢三个新名词。
- 把公式当讲解：先有可看见的意思，再出现写法。
- 「显然」「不难发现」「我们规定」。

## 一年级

- 怎么想：眼前有没有、数不数得清。
- 怎么讲：故事 → 摆一摆/数一数 → 再说算式 → 再数一遍。
- 词：一共、还剩、比……多；不用抽象定义。
- 画面：大图少字，核心过程用 `scene` 的实物示意、移动与高亮；`title`、`compare` 等用于题目或必要对照，不用文字朗读代替演示。
- 口播：短句、慢慢说，一次讲一个动作；不根据字数给时间轴填秒数。
- 练习：改数字再数一次，不要套娃应用题。

## 二年级

- 怎么想：事情在画面里发生，问「现在是几」。
- 怎么讲：全程对着图，一步一停。
- 词：几个几个地数、同样多；不讲字母、方程、抽象流程口诀。
- 画面：用 `scene` 展示需要看见的变化，按内容辅以 `compare`、`number_line`、`bar_model`、`formula` 或 `table`；每步保留可读的关键说明或等价图形标签，不是“少字”到只剩结果。算式配一句含义，表格标清数量和单位。
- 口播：短句，一步一停，但把一步的原因讲完整，不能只念算式或结论。解释本次题目中每个数量、操作或观察的含义。使用当前配置声音，不传接口未声明的语速字段。
- 练习：可省略；要有也是同一幅图改一个数。

## 三年级

- 怎么想：能跟「先算什么、再算什么」，每步仍要看见。
- 怎么讲：两步也可以，但每步配图；新词 = 词 + 指图。
- 词：周长就是绕一圈；分数最多到「平均分成几份、取几份」。
- 画面：`scene` 演示关键动作，可开始用 `steps`，每项对着刚才的动作。
- 口播：每句一个小步骤，讲完再进入下一步。
- 练习：一道同构图，数字更小。

## 四年级

- 怎么想：能接受「先变成一样的，再合并」，但要看见「一样」是什么。
- 怎么讲：图 → 给步骤一个短名字 → 写算式 → 跟练一题。
- 词：需要时先说大白话，再补真名。
- 画面：`scene` 展示变换或关系，辅以 `fraction_pies`、`formula`、`steps`，仍不要开头甩定义。
- 口播：先说观察，再说方法；仍保持清晰的句段边界。
- 练习：一道同构题，先留白再揭晓。

## 五年级

- 怎么想：能问「这一步为什么可以」，仍要一例贯穿。
- 怎么讲：方法名可以出现，但必须绑在这一例上。
- 词：未知数先说「先空着」，再出现字母。
- 画面：保持关键过程的 `scene` 演示，`formula`、`steps`、`quiz` 可更密。
- 口播：可以说明因果，但一段不要同时解释几个新概念。
- 练习：可加一题变式（只改一个条件）。

## 六年级

- 怎么想：能跟完整流程，仍要听人把理说圆。
- 怎么讲：步骤可压缩，可 `compare` 两种方法，每种讲清一次。
- 词：可以用学科名，仍配一句人话。
- 画面：两种方法并排可以，不要分类讨论清单。
- 口播：可以简练地串起完整推理，仍为关键画面动作分段。
- 练习：一道变式即可，不要试卷讲评腔。

## 题目相对该年级过难时

原则：保留该年级的想问题方式，丢掉超出的算法。一年级到六年级都这样处理。

举例（只是举例，不是只处理这些题）：

- 一年级碰到「还剩几只」：数出来即可。
- 二年级碰到异分母加法：只比较份的大小，不把它们加起来。
- 三年级碰到通分：讲清「平均分、取几份」，不进入异分母加法。
- 四年级碰到方程：仍用假设/图画，不列未知数。
- 五年级碰到比例：先把「同样的倍数」说清楚，不展开比例式。
- 六年级碰到竞赛分类讨论：收成一种讲得完的方法。

## 写稿自检

- [ ] `grade` 是小学 1–6 中明确的一个，不是「小学生」
- [ ] 讲解方式匹配该年级的「怎么想 / 怎么讲」，不是套邻近年级的现成稿
- [ ] 术语没有超出该年级的理解方式；出现的术语都立刻配了图
- [ ] 口播用词和停顿适龄；实际时长来自音频，没有猜测或伪造时间轴
- [ ] 换年级时口播和画面都重写了
