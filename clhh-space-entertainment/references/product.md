# CLHH 空间娱乐 AI OS 产品知识

## 核心定位

CLHH 是面向商业娱乐场景的空间基础设施，将演出控制硬件、内容系统和空间智能工作流结合在一起，为线下场馆提供“可编程娱乐现场”的能力。

## 四大能力维度

### VOD 场控与硬件调度

基于 BOXLINK 硬件，统一调度大屏或异形屏视频播放、灯光参数（例如 DMX、律动）和设备状态。描述该能力时，应强调内容、灯光与设备在同一个现场工作流中协同，而不是孤立的播放器功能。

### AI 内容生成与资产管理

结合场地类型、氛围关键词和品牌专属数据（Logo、标准色、视觉偏好）生成专属视觉 Loop。支持官方精选素材库与用户自有图片、视频和 Loop 的管理与即插即播。

### AI 互动礼物与商业增收

将现场送礼行为与声音、灯光、屏幕视觉反馈实时联动，形成全场爆屏和灯光特效。方案应同时考虑互动体验、节奏控制和商业转化，不把送礼描述成单纯支付动作。

### 运营数据飞轮

沉淀播放、灯光切换与互动反馈数据，用于持续改进 AI 提示词、素材选择和场景调度效率。不要在没有数据接口或分析结果时声称已经完成优化。

## 适用场景

- KTV 与派对房：歌曲、主题视觉、灯光律动、互动礼物联动。
- 酒吧：不同时段的氛围编排、演出节点和全场互动。
- 电竞馆：赛事信息、战队视觉、关键事件和灯光反馈。
- 沉浸餐厅：餐段、菜品或主题叙事驱动的视听场景。
- 商业展厅：品牌内容、空间导览和互动展示协同。

## 方案表达顺序

1. 识别场地类型、空间结构和当前运营目标。
2. 明确现场触发源，例如歌曲、时段、礼物、赛事事件或人工控制。
3. 编排屏幕内容、灯光、声音和设备动作的联动流程。
4. 指明所需素材、品牌信息、硬件与连接服务。
5. 说明哪些是方案建议，哪些可以由当前已授权 MCP 或 Tool 真实执行。
6. 给出可观察的现场结果与可沉淀的数据。

## 边界

- 本文档不证明 BOXLINK、屏幕、灯光、VOD、素材库或生成服务当前在线。
- 不要虚构 MCP 或 Tool 未声明的参数、默认值、分辨率、时长、性能或错误处理。
- 对真实执行，只相信已连接能力的描述、输入输出 Schema 和返回结果。
- 未执行的动作使用“可以配置”“建议编排”“需要连接”等措辞，不宣称已经完成。
