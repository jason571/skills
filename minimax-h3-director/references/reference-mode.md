# R2V / Full-reference 模式

当素材用于定义角色身份、服装、场景风格、道具、动作来源、视频结构或音色时，采用参考生视频模式。它的难点不在“多写细节”，而在让每项参考在全篇保持同一个身份和用途。

## 参考资产的角色

| 标签 | 用途 |
| --- | --- |
| `<Subject N>` | 从素材中抽象出的角色、场景、道具、服装、动作或风格单元 |
| `<Picture N>` | 作为明确关键帧、构图锚点或分镜参考的图像 |
| `<Video N>` | 提供延续起点、剪辑关系或时间结构的视频 |
| `<Audio N>` | 被复制或参考的声音、音色或音频结构 |

若图片只用于定义角色，不要同时把它写成关键帧。用户仅说“参考图片”时，默认保留其身份/风格用途，不锁定视频第 0 秒；只有用户明确提出首尾帧要求时才增加关键帧约束。若一项素材确需同时承担两种功能，分别说明两种作用。

## 推荐结构

完整提示词通常按以下顺序组织：

1. `subject_definitions`：逐项定义参考资产和要继承的属性。
2. `summary`：说明目标视频与主要参考关系。
3. `retention_analysis`：说明每项参考在何处出现，保留、迁移或弱化哪些属性。
4. `detailed_description`：用连续的镜头时间线描述画面、动作、台词、运镜和同步声音。
5. `overall_soundscape`：总结环境和物理声音。
6. `non_diegetic_music`：仅描述观众听到、角色听不到的配乐。

## 标签纪律

- 给素材编号的顺序必须与 ComfyUI 的连接顺序一致。
- 同一个角色、声音或物件不能在后文换编号或换名称。
- 每个引用都要说明它是保持身份、转移风格、参考动作，还是作为明确关键帧。
- 使用音色参考时，写清说话角色、逐字台词和音色来源；没有语音参考时不要暗示模型会复制某人的声音。
- 多段短剧中，同一参考素材可用于维持角色身份，但下一段剧情的起点应来自上一段**实际结束状态**。不要因再次使用同一参考图，就把人物重新放回原图姿态、地点或开场事件。

## 一致性取舍

参考图越多并不必然越稳定。对于单一角色，优先选择身份信息清楚、风格一致的少量素材；当多张图的服装、年龄、光线或视角冲突时，先让用户指定哪一张拥有优先级。
