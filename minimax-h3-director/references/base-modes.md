# Base 模式：T2VA、I2VA、FL2VA、L2VA

这四种模式共享一个原则：将视频写成可播放的视听时间线。英文提示词的核心通常包括视觉与动作时间线、整体声景和非画内配乐三部分。

## T2VA：从文字开始

没有关键帧时，在第一镜建立整体风格、构图、人物和空间关系。随后按真实发生顺序写动作、反应、运镜、声音和镜头切换。不要在没有视觉变化时强行新增镜头。

## I2VA：从首帧发展

把给定图片视为第 0 秒的明确锚点。先描述画面中已存在的人物、服装、物体、环境和构图，再写动作如何从这个状态自然开始。关键不是重复“保持一致”，而是描述什么保持不变、什么发生变化。

## FL2VA：在两张关键帧之间过渡

首图和尾图分别锁定开场与收束。优先用连续动作、姿态变化、物体移动、光线变化和构图演进建立可观察的路径。除非用户明确要求剪辑，少镜头通常更容易形成稳定过渡。

## L2VA：落到尾帧

给定图片是最后画面，而不是默认的第一镜。先推导合理的前置状态，再逐步写清人物、物体、镜头和光线如何趋近最后画面。最后一镜必须直接描述尾帧所锁定的构图和状态。

## 写作顺序

1. 用 `[Shot 1]` 建立风格和开场构图。
2. 在后续镜头的切换点写清单调递增的时间位置。
3. 每个镜头只描述当前可见的主体、位置、动作、相机和同步声音。
4. 用独立字段总结环境声和非画内配乐；不要把同一声音同时写进台词、声景和配乐。

## 关键帧对齐

I2VA、FL2VA 和 L2VA 都需要在提示词最前面表达参考图与视频时间点的对齐关系。具体字段和当前模型版本的精确格式以官方文档为准。写作时要保证：图片编号、所属镜头和时间点三者一致。
