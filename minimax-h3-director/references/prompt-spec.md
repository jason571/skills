# 结构化提示词规范

使用英文写提示词主体；仅保留用户指定的台词、歌词和画面文字原语言。将每个细节放到最恰当的字段中，避免重复和相互矛盾。

## 镜头与时间线

- 第一镜使用 `[Shot 1]` 建立风格、构图和初始状态。
- 后续镜头在明确时间点切换，时间应严格向前推进并落在目标时长内。
- 写出镜头内实际发生的运镜，例如推近、横移、跟拍、摇镜或静止；不要只写“电影感”。
- 优先用单镜头完成连续动作；只有叙事或视觉关系发生改变时才切镜。
- 每段提示词的最后一镜要给出明确的结束动作/构图；下一段从该结果继续，不重放开场。镜头时间戳按**本段生成时长**计算，全片时间戳只用于剧情计划。

## 台词与口型

- 将台词原文写进 `<d>[Language] ...</d>`，不要用“说了一句话”代替。
- 为每位说话者维持稳定标识，例如 `(S1)`。
- 如果是旁白，明确它来自画外，并要求画面人物不做同步口型。
- 用户要求原创短剧对白时可以创作台词，并逐字写进 prompt，标明是本次创作；若仅要求视觉片段，则不要强加人物讲话。用户提供的台词必须照录，已有歌曲歌词只用用户提供或实际核对过的文本，不凭模型记忆补写或冒充引用。

## 声音分层

- 主时间线：同期动作声、说话、唱歌和情节相关声音。
- `overall_soundscape`：环境声、物理声和非语言人声。
- `non_diegetic_music`：观众听到、角色听不到的配乐；没有时使用 `N/A`。

不要把同一段脚步声或音乐在两个字段中重复。配乐要描述乐器、节奏、力度和变化，而不是只有抽象情绪词。

## 可见文字与视觉约束

- 画面内文字用英文双引号保留原文，例如 `a sign reading "营业中"`。
- 在第一镜明确主风格；参考素材存在时，说明哪些风格元素应继承。
- 用具体的服装、道具、位置、光线和动作取代“高质量”“高级感”等不可验证的修饰语。
- 用文字写视觉和声音意图，用 MCP 的结构化参数传时长、画幅、分辨率、是否生成音频及参考素材；提示词中的“16:9”不会代替 `aspect_ratio`。
