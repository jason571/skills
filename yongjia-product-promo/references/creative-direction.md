# 按宣传对象选择叙事

本文件不是运行时必读。对象和口径以用户这句话为准；不必为了选题再读本文件。

多产业可混合；新行业按其产品和用户价值写，不要全县特产集锦。只使用已提供或可核实的事实。

| 宣传对象 | 叙事与镜头重点 | 解说信息 |
| --- | --- | --- |
| 文化旅游、目的地、民宿 | 抵达、进入、体验、人与环境；用有方向的运动串联空间。 | 来这里能体验什么、适合谁；路线、票价需有来源。 |
| 服装、鞋履、箱包 | 整体造型 → 材质 → 工艺 → 穿着/行走 → 收束。 | 可见设计与有依据的特点；不虚构认证。 |
| 特色文化、民俗、传统工艺 | 物件 → 工序与手部 → 人物 → 当代使用。 | 工艺与意义用白话；身份、年代需有来源。 |
| 农产品、食品 | 产地 → 采收 → 加工 → 食用 → 产品呈现。 | 风味、用法、产地；不编疗效或「有机」。 |
| 工业产品、设备 | 需求 → 结构/制造 → 使用 → 有依据的性能。 | 解决什么问题；参数、客户需有来源。 |

全片一份风格。上一段末镜停在可延续状态，下一段首镜从该状态展开。每段解说只推进一个具体价值，不要四段重复同一句空泛赞美。
